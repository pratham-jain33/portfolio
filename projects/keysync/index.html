Why I built it

I could learn the right hand from tutorials fine. The left hand? Never. So I built the tool I needed.

// any-tutorial

YouTube link in, notes out

Paste a tutorial URL or upload audio. The pipeline separates the piano, transcribes it, and maps every note.

  • All notes shown — no hand-splitting gimmicks
  • Start a build, close your phone, come back when it's done
  • Your builds save to your cloud library
// wait-mode

Mic that actually listens

Play along on your real piano. KeySync hears each note and waits for the right one — chords included, in any order.

  • Correct key glows, wrong key flashes red
  • Calibration wizard tunes it to your room
  • Live level meter so you know it hears you
// practice-tools

Practice like you mean it

Slow it down, loop the hard bar, count yourself in. Then check the report.

  • Tempo slider from 0.25x to 1x
  • A/B loop + count-in metronome
  • Post-run accuracy report, per-song mastery, streaks
