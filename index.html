I build software constantly.

Solo builder and school student in Bengaluru. I build software on a laptop and a phone with zero budget, and I build in public on X and LinkedIn.

  • School student. My parents want me studying for IIT and boards. I build instead. First revenue is my leverage.
  • Started with browser extensions. VoiceMail Pro drafts emails fast (~200 users). Carbolt makes your carbon footprint visible across food, water, and fuel (~600 users).
  • Built Bolo, a voice layer for Windows. Then pivoted it into Bolo Doctor — voice-based patient notes for small clinics, dictated in Hindi, Kannada, Hinglish, or English.
  • Built KeySync because I could never learn the left hand from piano tutorials. Paste a YouTube link, get falling notes, practice with mic wait-mode.
  • Ship MCP servers for fun: hackerearth-mcp gives any AI assistant a code run button in 24 languages; security-mcp grades website security and explains CVEs in plain English.
  • Operating model: build constantly, ship constantly. Restless by default.
